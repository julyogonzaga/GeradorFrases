# 💬 Gerador de Frases

Um gerador de frases estático, simples e rápido desenvolvido em **HTML, CSS e JavaScript puro**. O projeto **não utiliza Inteligência Artificial** nem APIs externas; ele trabalha selecionando e exibindo frases prontas a partir de uma coleção local pré-definida.

---

## 🚀 Funcionalidades

- ⚡ **Sem dependências/IA**: Funciona de forma 100% local e ultrarrápida.
- 🎨 **Interface Simples e Responsiva**: Estilização limpa e adaptável a telas de celulares e computadores.
- 🎲 **Geração Aleatória**: Exibe frases sorteadas aleatoriamente ao clicar em um botão.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do projeto.
- **CSS3**: Estilização personalizada da interface (`css/style.css`).
- **JavaScript (ES6)**: Lógica para seleção e exibição das frases (`js/script.js`).
